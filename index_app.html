📖 Discussion Text

1. Definition & Purpose

A discussion text is a text which presents a problematic discourse. This problem will be discussed from different viewpoints.

Social Function: To present (at least) two points of view about an issue, usually followed by recommendations or conclusions.

2. Generic Structure

  • Issue: Stating the issue which is to be discussed.
  • Argument For (Pros): Presenting the point in supporting the presented issue.
  • Argument Against (Cons): Presenting other points which disagree with the supporting point.
  • Conclusion / Recommendation: Stating the writer's recommendation of the discourse.

3. Language Features

  • Using Simple Present Tense.
  • Using relating verbs / copular verbs (e.g., is, are, seem).
  • Using thinking verbs (e.g., feel, hope, believe).
  • Using additive, contrastive, and causal connectives (e.g., similarly, on the other hand, however, therefore).

📝 Example Text: Homework for Students

Issue

There has been a lot of discussion regarding the necessity of homework. While some people believe it is essential for academic success, others think it causes unnecessary stress.

Argument For (Pro)

On one hand, supporters of homework argue that it reinforces what students learn in class. Furthermore, it helps develop independent study skills and time management.

Argument Against (Con)

On the other hand, critics claim that excessive homework leaves students with no time for extracurricular activities or rest. Consequently, it can lead to burnout and mental health issues.

Conclusion

In conclusion, while homework has its benefits in reinforcing knowledge, it should be assigned in moderation to ensure a healthy work-life balance for students.
